#Hough Transformation Computer Vision Project

In this program it allows user to implement a image with coordinates to find the objects by using Hough Voting.

Hough Voting is a computer vision technique designed to cast votes in the accumulator to detect lines or shapes

This program uses an accumulator which starts out as an array of 0's and each time an object is found a vote is assigned to it and shows and image with each object with a red circle shown.

In this case of my project it takes the image of a billiard table and detects each ball on the table and the spot ball as well marking it with a green ball

To run this program you will need to use vs code or some IDE that uses python and allows you to use command lines in the terminal. I would recommend using Vs code as I created the program using the intergrated development environment
